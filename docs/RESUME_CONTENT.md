## Project Title
**AI-Powered Finance Manager** | Node.js, Express, MySQL, JWT, Tesseract.js

## Short Description
Engineered a comprehensive financial dashboard application leveraging algorithmic AI rules and OCR integrations to automate personal wealth tracking, budgeting, and receipt logging.

## Key Achievements / Bullet Points
- **Architected a RESTful API** using Node.js and Express, supporting full CRUD operations for income, expenses, and monthly budget tracking with securely hashed passwords and stateless JWT authentication.
- **Integrated Machine Learning OCR** (Tesseract.js) to automate receipt parsing, accurately extracting merchant data and transaction amounts directly from image uploads to bypass manual data entry.
- **Engineered a Rule-Based AI Engine** generating dynamic financial health scores and automated spending anomaly alerts by cross-referencing trailing 30-day transactional arrays against predefined budget caps.
- **Implemented Voice-to-Text Entry** by combining the HTML5 Web Speech API with algorithmic backend string parsing to generate transactions naturally (e.g., "Spent $50 on food").
- **Hardened System Security** against production threats by integrating Express-Rate-Limit, XSS-Clean, and HTTP Parameter Pollution middleware, achieving 100% route sanitization.
- **Optimized Database Performance** across a normalized MySQL schema by injecting LRU memory caching on heavy analytical aggregations, reducing query times for dashboard metrics by over 80%.
- **Developed a CI/CD-ready Testing Suite** utilizing Jest and Supertest, simulating integration flows and reaching deep endpoint coverage using globally mocked databases.
